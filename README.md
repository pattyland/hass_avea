# hass_avea
[Avea](http://web.archive.org/web/20170930210431/https://www.elgato.com/avea) Integration for [Home Assistant](https://www.home-assistant.io/)

## Archived

This repository is archived because Elgato Avea is now officially supported by Home Assistant. Development happens in Home Assistant itself now.

Please use the official Home Assistant integration instead:

https://www.home-assistant.io/integrations/avea/

The official integration has been part of Home Assistant since Home Assistant 0.97 and works with current Home Assistant installations.

### Installing

Put the avea folder in your custom_components folder and add the avea platform to the configuration:
```
light:
  - platform: avea
```
